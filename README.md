# PRISMA – Sistema de Gestión y Consolidación de Información Clínica

Proyecto final del curso **SC-504 Lenguajes de Base de Datos** de la Universidad Fidélitas.

## Descripción

PRISMA es una propuesta académica orientada a la gestión y consolidación de información clínica en una única plataforma. El sistema permitirá registrar, consultar y administrar datos relacionados con pacientes, médicos, historiales clínicos, tratamientos e indicadores de salud, facilitando el acceso organizado a la información.

La información utilizada será registrada manualmente para simular escenarios del entorno clínico, manteniendo un alcance acorde con los objetivos y el tiempo disponible del proyecto.

## Objetivo del proyecto

Diseñar e implementar una base de datos relacional que permita gestionar información clínica de manera organizada, íntegra y disponible, aplicando los conocimientos adquiridos en SQL y PL/SQL durante el curso.
